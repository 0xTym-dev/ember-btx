Understanding the coin

What is BTX?

A Bitcoin-derived blockchain with one radical twist: its proof-of-work isn't hashing — it's matrix multiplication. That single change is why a Radeon can mine it well.

BTX is an open-source cryptocurrency built on the same battle-tested foundation as Bitcoin — it's a fork of Bitcoin Knots — so it keeps the familiar 21-million supply cap, halvings, and a UTXO ledger. What makes it different is the puzzle miners race to solve.

Instead of repeatedly running SHA-256 like Bitcoin, BTX asks miners to perform a large dense matrix multiplication and hash the result. This is called MatMul-PoW. Matrix multiplication is exactly the kind of math GPUs are built for — which is why graphics cards, rather than specialized hashing ASICs, are the natural way to mine it.

The puzzle

How MatMul-PoW works

Every attempt to mine a block runs this pipeline. Change the nonce, run it again, until the final hash lands below the target.

1

Derive the seeds

Two seeds are generated deterministically from the previous block's hash and the current height — so every block gets a fresh, unpredictable problem.

↓
2

Expand to matrices

The seeds expand into two large n×n matrices A and B over the prime field M31 (2³¹−1). On mainnet n = 512.

↓
3

Add nonce-dependent noise

A small low-rank noise term (rank r = 8), derived from the block header and the miner's nonce, is added: A′ = A+E, B′ = B+F. This is what changes each attempt.

↓
4

Multiply

Compute the dense integer product C′ = A′ × B′. This is the heavy lifting — millions of multiply-adds — and where a GPU's parallelism pays off.

↓
5

Hash & check

The product is canonicalized into a transcript, compressed, and run through SHA-256. If the digest is below the difficulty target, the block is solved. If not, try the next nonce.

Why it matters

Made for graphics cards

GPU-shaped work

Dense matrix multiplication maps directly onto the thousands of parallel lanes in a modern GPU. That's the same operation that powers graphics and AI — so consumer cards are genuinely good at it, not just tolerated.

Where Ember comes in

The reference GPU code targeted NVIDIA. Ember is a HIP/ROCm port tuned on real Radeon silicon — the first and currently only way to put an AMD card to work on BTX. See the guide →
