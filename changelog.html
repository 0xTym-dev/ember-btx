Changelog

What's new in Ember

Every release of the AMD GPU miner for BTX. Download any version from the releases page; ./install.sh verifies the checksum.

0.1.1 Latest 2026-07-04 release ↗
  • NewLive web dashboard. Run with --gui to open a local page showing real-time hashrate, accepted/rejected shares, GPU temps, power, clocks, efficiency, and a live log. Read-only; nothing leaves your machine.
  • NewDEEP TUNE auto-tuning. --deep-tune tries different batch sizes and CPU-feed settings, measures the scan rate for each, and saves the best profile for your card — loaded automatically on every later run. Add --tune-objective efficiency for nonces-per-watt.
  • ChangeCopy reworded to be neutral about other miners — Ember stands on being the AMD option, not on knocking anyone.
0.1.0 2026-07-04 release ↗
  • NewFirst public release. The first GPU miner for BTX that runs on AMD Radeon cards.
  • NewMulti-arch HIP solver in a single binary — RDNA2 (gfx1030/1031/1032), RDNA3 (gfx1100/1101/1102) and RDNA4 (gfx1200/1201). The runtime picks the match for your card.
  • NewLinux + WSL2 support, an install.sh preflight (ROCm / GPU arch / checksum / Python), and the ember launcher.
  • NewTransparent 1% developer fee, disclosed and logged every round.
