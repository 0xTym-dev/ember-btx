Why Ember

Built for the cards nobody else supports.

A HIP/ROCm port of the BTX reference kernels, tuned on real Radeon silicon — not a wrapper around a CUDA binary.

The only AMD miner

Until now, GPU mining for BTX has meant NVIDIA cards. Ember is the first — and currently the only — way to mine BTX on a Radeon GPU.

Efficient by design

The solver is memory-bound, so a modest core-clock cap holds full hashrate while cutting power by about a third. Mine all night without the guilt.

Honest about the fee

A flat 1% dev fee, disclosed in the open and printed in the log every round. No hidden connections, no surprises.

Install

Running in three commands.

Ember needs AMD's ROCm runtime, then it's a download, a preflight check, and go. Windows works through WSL2 — no native port required.

1
Install ROCm 6.x or newer (your distro's package, e.g. rocm-hip-runtime), then confirm your GPU is visible.
# confirm the GPU rocminfo | grep -m1 gfx # e.g. gfx1101
2
Download & preflight. Grab the latest release, then let Ember check ROCm, your card, and the binary checksum.
./install.sh
3
Mine to your own BTX address.
./ember --address btx1z…your-address --worker rig1
1
Install the AMD Adrenalin 26.1.1 (WSL2) driver on Windows, then set up Ubuntu.
wsl --install Ubuntu-24.04
2
Install ROCm for WSL inside Ubuntu.
amdgpu-install --usecase=wsl,rocm --no-dkms rocminfo | grep -m1 gfx
3
Mine — same launcher as Linux.
./ember --address btx1z…your-address --worker rig1

WSL2 supports RX 7000 and RX 9000 (RDNA3/4). RX 6000 (RDNA2) needs native Linux. Set clock/power limits in Adrenalin on the Windows side — they aren't reachable from inside WSL2.

1%

A transparent developer fee.

For about 1% of mining time — roughly 36 seconds every hour — Ember mines to the developer address instead of yours. The other 99% is entirely yours. That fee funds ongoing kernel work and support so Ember stays the fastest AMD miner for BTX.

  • Disclosed: the fee is logged at startup and on every fee round — nothing hidden.
  • Honest by construction: it lives in the compiled solver, and blocking its connection gives you nothing back, so there's no reason to try.
  • Fair: 1% is at the low end for GPU miners. If you'd rather not pay it, Ember isn't for you — and that's fine.

Questions

Good to know.

Is my payout really mine?

Yes. You pass your own BTX address on the command line and 99% of the work is credited straight to it by the pool. Ember never sees your keys — it only submits shares under your address.

Which pool does it use?

Ember mines to the public minebtx pool by default (stratum.minebtx.com:3333). You can point it elsewhere with --pool host:port.

Why is the solver closed-source?

The compute core is distributed as a signed binary — the same model every serious GPU miner uses. The launcher and client around it are open source, so you can see exactly how Ember talks to the pool and submits your shares.

Will it run on Windows?

Through WSL2, yes — ROCm officially supports RX 7000 and RX 9000 cards there, and the same Linux binary runs unchanged. A native Windows build isn't available yet.

My card isn't in the list?

The build covers RDNA2/3/4 gaming cards. If rocminfo shows an arch that isn't included, open a GitHub issue — adding an architecture is just a rebuild.
